# NPP Meta Campaign: Copy, Media Plan & Launch Checklist

## Campaign guardrails

The landing page positions NPP around inspecting the actual roof, explaining findings, and helping homeowners understand whether targeted repair is appropriate. Copy below avoids diagnosing a roof from an ad, guarantees, and claims that a minor issue will inevitably become major damage. The landing page currently identifies its form as a visual demo that is not connected to NPP's GoHighLevel CRM; that integration is a **launch blocker** until tested end to end.

## Recommended media plan

### Planning assumption

A practical initial test budget is **$3,000 over 30 days** (about **$100/day**), excluding production, taxes and agency fees. This is a planning scenario, not a market benchmark or performance forecast. If NPP has a different approved spend ceiling, scale the percentages rather than treating $3,000 as required.

| Allocation | Share | 30-day spend | Role |
|---|---:|---:|---|
| Local prospecting | 70% | $2,100 | Reach eligible homeowners across the actual MD/DC/Northern VA service area with all three static angles and the short video. |
| Creative test reserve | 20% | $600 | Compare video versus static and one message angle at a time; use enough time/spend to gather directional evidence. |
| Retargeting | 10% | $300 | Re-engage eligible page visitors and social/video engagers if the audience is large enough to deliver without excessive repetition. |

If the warm audience is too small to usefully spend $300, move that allocation to prospecting. If the total budget is below $1,500, avoid splitting into many ad sets: run a single local prospecting ad set with the full creative set, then add retargeting only after audience volume supports it.

### Structure and delivery

- Objective: **Leads**. Prefer website conversion with a verified `Lead` event after a successful, connected form submission. Until that is working, do not optimize for a false or unverified event; use a temporary approved lead destination only if it preserves consent and CRM handling.
- Geography: include only areas NPP actually serves. Start with one combined service-area prospecting audience to reduce fragmentation; split geographies only when spend and lead volume can support a meaningful comparison.
- Placements: begin with Facebook and Instagram automatic placements, using the prepared 9:16 video for Reels/Stories and 4:5/1:1 statics for feed. Check previews for text/logo safe areas before publishing.
- Creative rotation: use all three static messages and the video as distinct ads. For the $600 testing reserve, make one clean comparison (for example, small-signs versus repair-first angle) rather than changing copy, audience and format simultaneously. Avoid claiming a statistical winner from a small sample.
- Retargeting: include eligible non-converters from site visits and meaningful social/video engagement, with appropriate exclusions for submitted leads. Apply frequency awareness; if the audience is limited or stale, return the budget to prospecting.
- Review cadence: check delivery and tracking daily for the first 72 hours, then review twice weekly. Compare cost per valid lead, in-service-area rate, qualified-lead share, assessment bookings and downstream outcomes. Do not optimize to clicks alone. Set pause/scale rules after NPP establishes acceptable economics and lead capacity; do not assume a CPL target without actual margin and conversion data.

## Landing page and CRM launch checklist

### 1. Page readiness

- [ ] Replace demo-only page language with approved live business content; confirm the page is on the intended domain and secure.
- [ ] Connect the form to the correct GoHighLevel location/pipeline. Verify every field, service ZIP, issue type and consent value maps correctly.
- [ ] Confirm required fields, validation, mobile keyboard behavior, clear success state and duplicate-submit handling.
- [ ] Test click-to-call on phone and confirm the displayed phone number, service area, CTA and ad promise are accurate.
- [ ] Publish a current privacy notice and consent language. Have the responsible owner review applicable privacy/marketing requirements before launch.
- [ ] Verify the thank-you state and ensure refresh/back navigation does not create repeat lead conversions.

### 2. Tracking and attribution

- [ ] Confirm the correct Meta Pixel and, if used, Conversions API are installed on the production page and associated with the correct business/ad account.
- [ ] Verify `PageView` and the selected `Lead` event in Meta's test/debug tools. Trigger `Lead` only after successful form submission or verified call conversion.
- [ ] If both browser Pixel and server-side CAPI send the same conversion, confirm matching event IDs/deduplication.
- [ ] Pass UTMs (source, medium, campaign, content) and available click identifiers into CRM fields; preserve landing URL and campaign/ad identifiers where supported.
- [ ] Test event consent behavior and any cookie/consent manager; confirm call tracking/phone click event if calls are a conversion goal.
- [ ] Confirm the platform reports one successful lead per test form submission and no event fires on page load alone.

### 3. CRM routing and follow-up

- [ ] Confirm a test submission appears once in the correct CRM pipeline with source, timestamp, UTM values and consent state intact.
- [ ] Verify owner assignment, territory/service-area routing, email/SMS notifications, after-hours handling and response-time expectations.
- [ ] Verify deduplication, invalid phone/email handling, spam filtering and a clear process for out-of-area requests.
- [ ] Test the lead lifecycle from new to contacted, qualified, assessment booked, completed and closed/lost. Ensure outcomes can be reported back to marketing.
- [ ] If importing qualified or booked lead outcomes as offline conversions, map status, timestamps, consent and deduplication keys and test before using for optimization.
- [ ] Run real test submissions from desktop and mobile using each ad destination; confirm event receipt, CRM record, notifications and correct thank-you experience. Label/remove test records.

### Go/no-go gate

**Do not launch paid traffic until a real submission is stored in the CRM, staff receive it, and the correct conversion event fires exactly once.** The current page says its form is not yet connected to GoHighLevel or storing submissions, so that must be resolved first. Obtain privacy/compliance review from NPP's responsible owner; this checklist is operational guidance, not legal advice.
